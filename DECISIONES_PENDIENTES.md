# Decisiones pendientes antes de operar

La demo usa valores provisionales, no aprobaciones de una fundación real.

| Tema | Valor de demostración | Definición pendiente |
| --- | --- | --- |
| Nombre y marca | Fundación Demo; verde y marfil | Identidad autorizada, logo y lineamientos |
| Contenido | Tres iniciativas ficticias | Misión, objeto social, metas y evidencias reales |
| Jurídico / tributario | PDFs sin validez | Revisión profesional en Colombia y jurisdicciones admitidas; documentos y requisitos aplicables |
| Identidad beneficiaria | Ninguna cuenta ni entidad legal real | Fundación receptora verificada, cuentas autorizadas y facultades |
| KYC / AML | Decisión manual ficticia | Proveedor, listas, reglas, responsables, tratamiento de falsos positivos |
| Pagos | COP/USD y métodos ilustrativos | Países, monedas, proveedores, costos, conciliación, devoluciones y reversos |
| Firma | Aceptación visual | Proveedor y mecanismo con validez aplicable; conservación de evidencias |
| Política de datos | Consentimiento ilustrativo; localStorage | Base jurídica, consentimiento, retención, derechos, seguridad y transferencias |
| Secuencia documental | Perfil → revisión → documento → pago → constancia | Orden definitivo y efectos de cada paso |
| Accesos | Selector de presentación | Autenticación real, permisos, recuperación y administración |
| Internacional | Países de ejemplo | Jurisdicciones admitidas y requisitos transfronterizos |
| Persistencia | Navegador local | Modelo de datos operativo, RLS de Supabase, backups y auditoría |

No se incluyen afirmaciones normativas definitivas, costos comerciales aprobados ni certificaciones oficiales.
